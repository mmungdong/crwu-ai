## 1. 现状协同机制（调研结论：skill 与知识库内容如何协作）

### 1.1 内容侧
- KB 本体 = 本地静态目录 `~/.crwu/knowledge/knowledge-base`（根常量 **CRWU_KB_ROOT** 字面写在各技能内；该副本由 dingcli 等从钉钉同步——**本质是正文文件缓存**，本方案目标=让其退出推理链路）。
- 顶层目录：`00-总纲`（执行契约 01–04 / 治理：标签词典·待人工发布清单·回测·校准·kb-index.jsonl）· `01-业务路线` · `02-资产类型` · `03-评估方法` · `04-监管覆盖` · `05-风险案例` · `06-规则库` · `README.md`。
- 规则/清单 = md 锚点块 `### RULE-xxx` / `### CHK-xxx`（type/authority_level/confidence(含 A 待发布)/dims/modules/**原文**/判定要点），kb_tool 解析为索引 `{id, file, start/end, release, hash}`。

### 1.2 技能侧引用形态（现状三类，均把本地静态副本当推理基座）
① 根常量字面（`CRWU_KB_ROOT=~/.crwu/knowledge/knowledge-base`）；② `KB/<层级路径>` 相对引用（装配表指针、契约文档、门禁清单、目录级引用）；③ 编号+行号（行号区间=本地静态文件锚点行号）。

### 1.3 推理装载路径（现状）
门禁读本地清单 → 装配（kb_tool，部署注入）或手工按装配表读本地文件 → 按本地文件:行号引用原文 → 输出三段式意见。

### 1.4 结论（痛点）
技能依赖"本地有一份最新同步副本"——即**正文文件缓存**；可能过期、换库失效；下载集合与审核需求解耦（先同步全量，后才知道要什么）。

## 2. 目标协同模型（用户口径 v0.2，R1–R5）

- **R1 正文永远实时**：每次审核需要引用的知识库正文，都在该次审核内从钉钉**在线实时下载**；下载时刻即最新，审核依据只出自本次下载的内容。
- **R2 文件零缓存**：不存在任何"可复用的正文副本"——不设正文缓存目录；本地静态内容副本退出推理链路；跨审核/跨案例一律重新下载，上一次的文件不得充当本次依据；审核临时下载物只属于本次（工作目录/临时区生命周期）。
- **R3 清单驱动下载**：本次要下载哪些文件 = **crwu-audit 画像/路由 + 命中子技能**后确定的引用文件清单（各子技能装配路径表 + 执行契约/门禁清单路径的并集）；下载按清单定向执行、逐文件核验，不多不少——**不需要全库镜像/预取**。
- **R4 目录可缓存（唯一缓存）**：只有"目录结构与路径索引"可本地缓存（`~/.crwu/knowledge/dws-dir-cache`，v0.3 语义）：回答"文件在不在库内、在哪个层级路径、nodeId 是什么"；未命中自动在线刷新。目录缓存中**永远没有正文**。
- **R5 技能引用形态**：技能只写 RULE/CHK 编号 + **库内层级路径**；不写知识库名称、不写本地根路径、不写 nodeId；引用原文时出处 = **本次下载文件内的锚点定位（文件:行号=下载文件实际行）+ 下载时刻**。

## 3. 审核期"文件清单 → 实时下载"流程（目标态）

```
crwu-audit 总路由（画像/路由/门禁）
  └─ 命中 L1/L2 子技能（如 realestate / realestate-rent / datacheck）
       每个技能携带引用路径表（装配表：清单文件、规则文件目录、契约文档、门禁清单）
       路由汇总 = 本次审核文件清单（层级路径[]，可含目录级→展开）
  └─ crwu-dws：按清单实时下载（M3 单篇实时 / 按清单批量实时=M2 定向）
       逐条：目录树定位（缓存命中快速路径 / 未命中自动刷新）→ 在线导出正文 → 落案例工作目录
       逐文件核验 + manifest（exportedAt/evidence）
  └─ 子技能只读"本次下载文件"：按锚点（### RULE/### CHK/标题）定位原文与行号
  └─ 输出：三段式引用（出处=本次下载文件:行号，证据含 exportedAt、库内路径、resolve nodeId）
  └─ 审计结束：下载物随本案工作目录留存（属该案材料，重跑/新案一律重新下载）；任何副本不进缓存
```

## 4. crwu-dws 侧增量（v0.4 设计要点，实施时单列纪要）

1. **路径寻址**（M3 扩展）：输入支持库内层级相对路径（`<目录>/<文件>.md` 或 `<目录>/` 目录级）→ node-index 增全路径键（folderPath+name 链）→ 精确/目录前缀匹配 → 未命中自动刷新目录缓存 → 重查 → 仍无如实报告；歧义全列请消歧。
2. **按清单批量实时下载**（审核消费主路径；=M2 定向子集）：输入 = 本次审核文件清单 paths[]（可含目录级）→ 逐条解析 + 在线导出正文 → 落案例工作目录同构子路径 → manifest 逐文件记账 → 摘要 成功/失败；**每个文件都是当次在线导出（exportedAt 逐文件）**。
3. **M2 全量镜像**：降级为"用户显式留档/备份"场景（保留命令与语义）；**不再作为 crwu-audit 推理的参考路径**（推理走 §3 清单定向实时下载）。
4. **目录缓存红线不变**：dws-dir-cache 只存 目录快照/目录树/node-index/.cache-meta 四件，永不落正文（references/02 §4 红线同款）。
