# 可检查、可纠正、可恢复的估值图：初版设计

> **历史快照**：本文是 2026-10-17 的设计记录，不作为现行操作指令；正文保持原样，
> 其中"尚未实施 / 未验收"的表述按当时事实保留。当前实现说明见
> [`plugins/dsh-crwu-workbench/docs/valuation-workflow.md`](../../../plugins/dsh-crwu-workbench/docs/valuation-workflow.md)。

本文记录用户在 2026-10-17 后续讨论中确认的实现方向，取代早期设计中“只在内存运行、不恢复”和“只展示七个阶段列表”的假设。此前实现仍可复用，本文不表示功能已经验收。

## 用户目标与已确认约束

- 资产评估工作台以业务流程入口展示，估值是当前第一个业务步骤；后续步骤尚未定义，不虚构业务节点。
- 进入估值后上传材料、填写估值对象/补充要求、选择方法（可自动判断）、可上传计算表；未上传时按知识路径通过 DWS 取得模板。
- 图承担路由与执行。DS 只接收当前节点输入、输出结构化结果。方法、参数、数据路径、模板均须有可核对依据。
- 分析方案时就实际验证可用来源：找到目标或有理由的邻近小区，打开详情并取得所需数字；方案展示将填写的具体模板和字段映射。
- 用户确认方案后正式执行。用户已确认的同口径备用来源可复用，改变方法/区域/案例性质/模板等需形成新方案供确认。
- 页面展示真实 Graph 的全部可展开节点、输入、输出、补充提示词、依据、证据及实际分支。知识、材料、用户修订、程序计算、模型判断按字段区分。
- 用户可校正输入与模型判断，生成新修订；程序金额通过参数/公式变更重算。保留原始用途“公寓”、建筑面积与套内面积的区别。
- 未选择基准日即留空，不补今天、不作为通用必填；具体知识条款需要时才产生相应缺口。
- 本地 SQLite 放在用户 `.crwu` 中。按“每个工作空间、每个业务步骤保留一份当前任务”实现；检查点及当前任务内的修订允许多行，不扩展多任务历史产品。
- 可导出/加载/清空当前图。重启自动展示已保存状态，继续前核对真实会话与已生成文件，不自动重复执行未知状态的外部动作。
- 用户明确授权 DSH 真实验收，测试文件为 `~/Documents/6-力鸿花园产权证.pdf`，选择房地产、方法自动判断。原文件不改写。

## 实现边界

### Graph 层

保留 `src/host/graph/graph.ts -> valuation/graph.ts -> valuation/realestate/graph.ts` 的真实编译子图和注册函数。预处理、方法分析、来源探测、模板适配、确认、执行等均由实际节点或实际嵌套子图驱动；页面读取其拓扑和节点元信息，禁止另画一份与执行脱节的固定流程。

内部节点可按“分析方案/执行估值”分组。主图不导入 DSH、文件系统或 provider；Host 适配层注入真实能力。节点输出采用固定 schema，DS 不收到命令、凭据或自行调用工具的权限。

### 业务与 Host 适配层

复用已存在的知识物化、材料提取、市场搜索/详情采集、计算和成果语义校验。模型选定条款/来源后由程序核对引用、版本、适用性、价格与单位；计算结果不得由模型口算填入。

来源顺序采用用户指定的链家、房天下、安居客、58 同城。单一来源失败仅影响该来源。标为可执行的路径必须实际取得必需字段；未验证的备用路径显示未验证。模板使用实际上传或知识附件，做字段映射、公式/量纲/可写区域验证，形成可查看的预览。

现有专业计算切片是挂牌参考，正式市场法/收益法/成本法不能仅有界面选项便宣称已具备。能力分析明确当前实际可计算口径，用户确认后执行。需要新模板适配时，先做真实验证；不得悄悄以自制表替换用户/知识模板。

DSH 父会话通过一个工作流控制 Tool 驱动图，使用真实调用上下文。组合调用既有市场工具走公开 SDK ToolRuntime.execute，不伪造 token/context。节点推理使用独立、工具集为空、强结构化输出的子会话。控制 Tool 在暂停/完成后结束该轮，避免外层 Skill 重复编排。

### 当前状态与恢复

图定义与版本在代码；数据库保存当前业务任务指针、节点检查点、采用值、修订/提示词补充、待确认问题、真实会话关联和证据索引。原始材料、模板和成果保存在项目目录。

使用 LangGraph 检查点保存实际执行状态。`runId` 关联 `thread_id`，子图保留命名空间；DSH sessionId 另存，不能混作路由键。SQLite 通过具名 Broker 授权与诊断记录访问，使用 DSH 支持的 Node 内置 SQLite，缺失/探测失败/执行失败分别结构化上报。

节点结果、确认及修订以事务提交。任务导出来自一致的已提交快照，加载校验格式/图版本/归属/文件引用；不得执行导入数据中的任意代码或路径。清空只作用于指定当前任务及其检查点，先确认执行已经停止，成果文件独立保留。

重启后恢复展示；原运行中节点标为中断待核对。继续前重绑真实项目和工作区、验证冻结材料与已产出文件、核对会话和操作结果，复用已完成成果，之后驱动未完成节点。

### Client 层

业务首页使用流程入口。估值工作面以真实图为主，节点详情展示本次输入/输出/依据/证据/补充提示词/修订；主次信息按需展开，中文、主题 token、窄屏可用。

方案确认展示方法依据、实际来源路径与可取字段、使用模板/区域/映射、执行范围与限制。用户修改时先展示服务端影响范围，再提交明确版本；迟到响应、重复提交、切页、Host 版本不一致均不覆盖新状态。

导出/加载/清空/继续为明确操作。恢复页面本身不重新调用 DS，也不重跑取数。进度只来自真实节点和工作量，不伪造百分比或“思考过程”。

## 验收

1. 真实嵌套图注册/路由/数据流、节点输入输出校验及知识引用；文件驱动意图和多对象歧义显式处理。
2. 单个节点可检查、修订、查看影响并驱动依赖；人工修订与模型输出可区分，金额仍有计算轨迹。
3. 实际 SQLite 关闭重开、原生 Graph 中断恢复、子图命名空间、导出加载和条件清空。
4. 页面实际启动到工作流控制 Tool，停止/重试不产生第二轮；确认前不正式执行采集和计算。
5. DSH 实例使用指定扫描 PDF，保留用途/面积口径，走真实知识、真实来源和真实计算；交付计算表、报告数据、HTML、轨迹，来源可追溯。
6. 单测/类型/构建/产物加载/包验收、`make plugin-check`、`make docs-check` 与最终 diff。浏览器使用已装 Edge；macOS 实测与 Windows 未验证边界如实记录。
