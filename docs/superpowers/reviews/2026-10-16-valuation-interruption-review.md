# 房地产估值中断会话复盘与知识库校正清单

> 历史评审快照，记录 2026-10-16 的归档分析及本机实测；不是当前操作指令。
> 修复状态见文末验收记录，不能用本报告替代运行中的工具契约。

## 结论

本次没有形成估值，主要原因是工具与工作流把能够继续的工作反复变成了阻断：旧 manifest
拦在 Excel 下载之前、重复下载撞上已有文件、来源索引被覆盖、已创建方案未登记执行权限，
以及没有把用户要求的挂牌参考测算接到实际计算和交付入口。不能归结为“知识库不完整”或
“网上没有成交价”。

本次用户已明确选择：成交资料取不到时，默认输出 **挂牌参考估值**，列明单价、总价、来源及
限制，保持挂牌性质。这个选择来自当前会话；压缩包内的历史指令只作为复盘证据。

## 已复现的问题与处理方向

| 问题 | 证据 | 应改行为 |
| --- | --- | --- |
| Excel 下载前被旧入口挡住 | 模板工具因旧 `00-知识目录与必需项` 不存在而退出，尚未调用二进制下载 | 直接按 Wiki 返回的真实 XLSX 路径解析、用 DWS 下载；不要求业务人员补旧 manifest |
| 重复物化失败 | 同一批正文先读取，再请求参数；固定输出路径返回 `LOCAL_FILE_EXISTS` | 复用已回读校验的本轮快照，或使用新落点；保护旧文件 |
| 来源索引丢失 | 失败后汇总索引没有保留已成功来源，agent 手工重建 | 累积保存来源；新失败单独登记；损坏索引显式报错，不能重置或跳过坏条目 |
| 自己的方案无法执行 | 创建方案成功后，调度仍报无权访问 `plan-001`；真实工具接线已复现 | 持久化成功后登记本轮方案权限，并同步可恢复项目记录；不放宽跨项目门禁 |
| 公寓被强迫先改成住宅 | 两份权证的“规划用途”确为“公寓”；业务词表没有公寓类别，分类依据被留空 | 保留公寓类别及权证坐标，同用途检索及挂牌参考继续；住宅专属规则需要时再核细分口径 |
| 挂牌要求未进入计算 | 取得挂牌渠道记录，用户多次要求参考测算，最终仍没有金额和工作簿 | 独立挂牌参考入口；选定样本、原始报价、比较理由、算法、金额及限制同步交付 |
| 单一渠道失败被泛化 | 一个成交渠道出现验证码后，回复称“网上取不到成交价已核实” | 只陈述已查渠道、页码、时点和失败范围；保留已取得数据 |
| 数值检查与正文不一致 | 单项检查实际比较了系数总积，`combined_limit` 读取后未使用 | 分开检查细项、已明确分组的类别及共同幅度；不得互相代替 |

### DWS Excel 的实际边界

本机使用随包 DWS 1.0.61，从真实知识库节点下载住宅模板到隔离目录：成功，25,512 字节，
OOXML 必需部件和 ZIP CRC 检查通过。文件 SHA-256：
`f2e8f15e54299afb3c5a6d269791c6e7401b4112c69f70347a8aeb2634e1e08d`。

再次下载到同一已有文件，退出码 5，错误码 `LOCAL_FILE_EXISTS`；原文件指纹保持不变。
因此至少存在两种不同故障：估值工具在下载前被旧入口挡住，以及调用方重复使用已有输出路径。
直调成功不代表 Workbench 整条链路已修好，也不代表所有平台、网络和员工环境均已验证。

“文件可以取回”与“旧模板可用于自动计价”应分别报告。真实填写说明已经标注旧模板待修订与
重算验收，同时允许附件修订前用文本表、CSV 或项目程序记录计算过程。

### 住宅 Excel：实际核对的公式问题

以下问题多数已经被真实《住宅模板填写说明》列出。本次对下载附件进行了静态核对，证明它们
仍然存在；**未宣称已修复，也未宣称 Excel／LibreOffice 已重算通过**。

| 工作表／位置 | 实际内容或缺陷 | 校正与验收方向 |
| --- | --- | --- |
| 案例 `E63` | 引用 `保留数`，而工作簿没有定义名称 | 建立明确有效的计数引用，检查保留集合与分母一致 |
| 价值内涵与税费 `B34:B35`（同类列同查） | `B34=B35`；`B35=B28+B33+B34`，构成循环 | 按已核实价格桥接和税基重建关系，不能随手删一格或补零 |
| 价值内涵与税费 `B36`、`B38` | 分母为 `$B$33` 税额合计，未使用对应案例面积 | 对齐各案例面积和总价；逐项核对量纲 |
| 价值内涵与税费 `B37` | 单价与总税额相减，口径不一致 | 在统一的总价或单价层完成桥接 |
| 价值内涵与税费 `F28` 等说明格 | `=交易价格*10000` 等中文说明被保存为公式 | 改为文字说明；真正公式引用明确输入单元格 |
| 市场法 `N6:P34` | `CONCATENATE` 生成文本，还引用了事实栏 | 使用对应指数计算数值系数，回读确认类型与方向 |
| 市场法 `B37:E37` | 引用错误事实范围，乘积范围止于第 33 行 | 按类别和明确因素范围计算，覆盖实际第 34 行；检查分组与共同幅度 |
| 市场法 `B38:E39` | 对象列与三个案例列混入均值 | 仅对实际保留案例求值，逐项核对分母和选组 |
| 市场法 `B42` | 引用基础信息 `B10`，填写说明指出应取适用税费参数位 | 先核含义和适用记录，再修引用，不直接套模板预填值 |
| 市场法 `B45:B47` | `ABS(100-B7:E33)` 检查事实与指数差；其余依赖上游错误 | 分别输出细项、类别、共同幅度和正数案例离散度，不只显示“OK” |
| 估值结果汇总 `G5` | 收益法只取 `C30`，未包含终值及合计口径 | 按实际收益模型核对期间收益、期末权益及总额 |
| 估值结果汇总 `K5:K14` | 按方法文本搜索，多个方法时优先命中收益法 | 单法映射与多方法结果协调分开，采用方法及协调依据可复核 |
| 估值结果汇总 `G6:I14`、`C19` | 对象链接不完整；面积比较仅内部求和 | 逐对象核对，面积覆盖应与独立权证清单勾稽 |

附件修复后，应使用明确测试输入、预期中间值和结果，在实际表格引擎中重算并回读，再修改
知识库的模板状态。静态 ZIP、公式存在性或 openpyxl 打开成功均不足以宣布正式可用。

## 执行流程优化的验收标准

1. 资料先给出对象事实、出处和实质冲突。权证明确为公寓时保留公寓，不把住宅确认设为通用入口。
2. 入口 Wiki 取一次；按本次分支批量读取必要正文。同一活动项目复用完整、已验证目录树，失败和
   不完整目录不缓存；其他项目及新会话生命周期不继承这份缓存。
3. 同一正文复读先核对本轮快照，不再重复导出；已有索引损坏时明确报错，保留证据和可恢复动作。
4. 同一列表页成功采集后复用完整行数据，不重复导航。详情只访问实际需要核实、选中的案例。
5. 选中详情保存实际网址和 PNG；Excel 展示完整网址及图片相对路径，HTML 同样能够找到原图。
6. 成交资料不足时按本次用户已选的挂牌参考分支继续。已确认的用途或输出偏好持续有效，新增实质
   冲突才提问；不反复请求同一授权。
7. 挂牌参考的计算轨迹、Excel、报告数据和 HTML 由一次受控构建生成；检验按实际文件执行。
8. 数据及文件未变化时，不重复生成同一份阻断报告、重复 finalize 或创建无变化修订。

以上是可检查的调用和交付标准。尚未完成真实站点、全链路及 Windows 运行时验收前，不承诺
固定分钟数或声称端到端提速比例。

## 浏览器与运行边界

浏览器不要求必须 Edge。当前 CDP 通道支持可用的 Chromium 系浏览器，如 Chrome、Edge、Brave、
Chromium；Safari、Firefox 不能直接沿用这条 CDP 通道。浏览器选择应遵守已探测能力和用户配置。

已有本机验证说明：普通抓取可使用自有浏览器目标、不主动切到前台，遇到需要人工处理的验证再
展示；macOS 最小化窗口会导致截图超时，所以不把“后台”实现成强制最小化。不承诺操作系统
层面完全无窗口，也不保证网站永远不拦截。通过串行、缓存、合理节奏及保留断点减少无效访问。
