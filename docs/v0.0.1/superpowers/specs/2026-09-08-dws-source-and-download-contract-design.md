# DWS 知识源与审核下载契约设计

## 目标

统一 `crwu-dws` 与 `crwu-audit` 技能族对知识正文来源和下载范围的描述：钉钉知识库是唯一正文来源；本地不存在离线知识库；每次审核仅按本次清单从钉钉下载所需正文。

## 边界

- 删除活动 Skill、装配表和设计文档中的 `CRWU_KB_ROOT`、本地静态知识库、离线归档、正文副本兜底等表述。
- 删除 `crwu-dws` 的 M2-B 整库镜像能力。
- 保留不含正文的目录/节点元数据缓存，用于定位节点；缓存不能作为知识正文来源。
- 保留当前审核下载物。它只属于本次审核工作集，跨审核必须重新下载，不得作为离线知识库复用。
- 不删除 `/Users/mungdong/code/knowledge-base` 目录，不修改其中内容；本次仅修正 Skill 及其活动设计文档的运行契约。
- 不覆盖 `skills/crwu-audit/SKILL.md` 中现有未提交的人工复核材料隔离修改。

## 下载协议

审核路由和叶子 Skill 产出本次下载清单。每个清单项均为知识库内层级路径，允许混合两种类型：

1. 文件路径：只解析并下载该文件。
2. 以 `/` 结尾的目录路径：递归解析并下载该目录下全部支持的正文文件。

清单外文件不得下载。无法解析、下载失败或文件类型不支持时，必须记录路径和原因；不得回退到本地正文或推测内容。正文需记录 `nodeId`、库内路径、`exportedAt` 和本次下载文件信息，以便审核结果追溯。

## 模式调整

- M1：查询钉钉知识库目录并维护无正文的目录元数据缓存。
- M2：按本次审核清单下载正文；同时支持单文件和目录条目。
- M3：按文件名、库内路径或 nodeId 定位；需要正文时从钉钉现场下载。
- 移除 M2-B 整库镜像及其备份、离线归档、读取优先级说明。

## 修改范围

- `skills/crwu-dws/SKILL.md` 及相关 references。
- `skills/crwu-audit*` 中有关正文来源、目录下载和装配表的活动说明。
- `skills/README.md`。
- `docs/design-audit-live-kb-protocol.md` 与 `docs/design-crwu-dws.md`。
- `docs/CHANGELOG.md` 只追加新记录，不改写历史记录。

## 验证

- 静态检查活动文件中不再把本地正文、`CRWU_KB_ROOT` 或离线归档作为可用来源。
- 静态检查活动文件中不存在 M2-B 整库镜像能力。
- 验证单文件、目录和混合清单三种行为均有明确且一致的契约。
- 验证目录缓存仍明确禁止保存正文。
- 运行受影响 Skill 的 `quick_validate.py`。
- 运行仓库现有知识库/Skill 校验；若失败，区分本次回归与既存问题。
