# 给 DSH：蓝色 AI 工作台候选视觉方案

> 交接快照：2026-10-15。用户提出使用 Ant Design 风格的蓝色，与 DeepSeek 小鲸鱼搭配。本文件用于该方向的试色与评审；前一份红色方案保持为历史候选。

本轮采用“**中瑞红负责品牌身份，蓝色负责 AI 与交互**”的视觉分工。保留用户选择的“任务聚焦”布局：单张工作纸、紧凑真实阶段提示、核心条件分组和清晰确认抽屉。以 Ant Design 蓝色为色板起点，沿用当前插件的组件、主题机制和加载边界。

## 1. 色彩角色

- 中瑞品牌：保留现有 `BrandMark` 与品牌红 `#D84A4A`，集中用于标志和品牌身份。
- AI / 操作：主按钮、当前导航、下拉选中项、focus、任务阶段和 AI 标识统一使用蓝色系。
- DeepSeek 小鲸鱼：继续用现有真实图形与官方原色；蓝色界面与其形成同色系搭配，无需把两者说成同一精确品牌色。
- 底面：浅色使用冰蓝灰底与白色工作纸；深色使用墨蓝灰底与更亮一层的表面。替换上一候选方案的粉灰底与红色光感。
- 错误 / 风险：维持业务语义色。中瑞红标志与红色错误通过位置、文字和图标区分。常规 AI 操作全部走蓝色，避免红蓝双主色竞争。

Ant Design 官方源码的默认 `colorPrimary` 为 `#1677ff`，以此为基础衍生背景、交互和强调色。[官方色板源文件](https://github.com/ant-design/ant-design/blob/master/components/theme/themes/seed.ts)

## 2. 色板起点

以下是本插件候选映射，深色及按钮配对属于本轮设计建议，不声称与 Ant Design 默认算法完全一致。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 品牌原色 | `#D84A4A` | `#D84A4A` |
| AI 基色 / focus | `#1677FF` | `#69B1FF` |
| 正文链接 / 强调文字 | `#0958D9` | `#69B1FF` |
| 实心主按钮底 | `#1668DC` | `#4096FF` |
| 主按钮配对文字 | `#FFFFFF` | `#101A2B` |
| 工作台底 | `#F3F6FC` | `#10141D` |
| 工作纸 / 抽屉 / 浮层 | `#FFFFFF` | `#181F2C` |
| 次级表面 | `#F8FAFE` | `#202A3A` |
| 主文字 | `#1D273B` | `#EDF3FF` |
| 次文字 | `#64748B` | `#A3AFC4` |
| 装饰分界线 | `#DCE4F0` | `#344156` |

`#1677FF` 作为色板基色；普通小字号的白字主按钮采用稍深蓝色并验证对比度。不要把所有蓝色文本、底色、描边都设成同一值。装饰分界线不承担必要输入边界的全部职责。

所有颜色集中在 `src/client/styles/tokens.ts` 的明暗语义槽中，组件引用 token。保持 `--crwu-brand` 的身份用途，另设或复用 AI/操作语义色。现有代码里把 `brand` 用于导航、focus 的位置应按新职责迁移，不能全局替换品牌红后让标志也变蓝。

## 3. 视觉落点

1. 顶栏保留真实中瑞品牌；AI 功能标识使用浅蓝底与蓝色图标。
2. 主导航当前项用蓝色文字与明确标记；次级导航/下拉选中项使用浅蓝背景和形状提示。
3. 页头局部可有低浓度蓝色柔光，工作纸正文保持不透明。光感集中在顶部与 AI 操作周围，不把整个页面涂成蓝色。
4. 核心条件区使用约 4%–6% 的蓝色浅底；普通补充字段维持清晰输入边界。资产类型和评估方法仍在文件选择区正下方，均必填。
5. “核对资料”“开始估值”使用蓝色实心主操作，选择文件、返回、登录、检查使用中性次级按钮。
6. 确认抽屉沿用同一色板、共享外壳和输入摘要层次，页头允许轻蓝光感；资料与用户提示词保持正常正文颜色。
7. 审核页、环境页和共享控件使用同一套操作色与表面层次。保留报告风险语义，避免只让估值页变蓝。
8. 动效沿用前一份方案：局部 hover/focus 约 120–160ms、下拉约 150ms、抽屉约 200/150ms；真实 pending 才有任务反馈，减少动画时立即完成过渡。
