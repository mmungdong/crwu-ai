# 监管覆盖层分类与 ROUTE 冲突

| 版本 | v1.0 | 状态 | 2026-09-09 定稿 | 维护 | `overlays[]` 与 ROUTE001–004 唯一事实源 |
| --- | --- | --- | --- | --- |

覆盖层只追加一类规则集或检查点，不改变范围、资产、业务或方法分类。机构 A/B/C 审核风险分类见 [09-review-risk-classification.md](09-review-risk-classification.md)，只影响严谨度提示，不是 overlay。

## canonical 覆盖层

| overlay 标签 | 判定信号 | 追加检查点方向 |
| --- | --- | --- |
| 国资 | `F0000082` 非空；`subtype` 保留国家国资委、地方政府、其他部委、财政部等原值 | 批准链、核准/备案、使用有效期、处置交易限制 |
| 证券 | `F0000127=是`，或新表单细分 `F0000188/F0000190/F0000191/F0000192/F0000195=是` | 收入/合同真实性、披露一致性、预测实现率 |
| 司法 | `F0000126=是`，或报告名称真实命中法院、执行、涉诉、司法 | 委托范围、基准日、争议事实边界、证据规则 |
| 金融/银行 | `F0000124=是` | 金融监管口径、不良债权可收回性 |

对四类 overlay 独立检查，每次命中后继续扫描。`overlays[]` 是多标签数组，例如国有上市公司的司法执行项目可同时保留 `国资 + 证券 + 司法`；各 overlay 对应技能取并集，不得用优先级或排他链删除其他命中。

`F0000123`（是否国有）与 `F0000082` 高度冗余，不参与 overlay 路由；`F0000122`、`F0000125`、`F0000128`、`F0000130`、全空的 `F0000189` 及未定名的新表单标志只进入“字段名册待确认”，确认语义前不得据此装载覆盖层。

每个标签按 00 记录 `type/source/evidence/location/confidence/review_required`。名称命中只能作为相应规则明确允许的补充证据，不得把主体名称或行业常识泛化成监管标志。

## ROUTE 冲突检测

| 编号 | 冲突 | 严重度 |
| --- | --- | --- |
| ROUTE001 | 经济行为/业务目的：记录字段与委托合同或报告声明冲突 | S0/S1 |
| ROUTE002 | 评估对象或范围冲突 | S0 |
| ROUTE003 | 评估基准日冲突 | S0/S1 |
| ROUTE004 | 价值类型冲突 | S1 |

冲突证据必须来自字段直读或已真实读取并定位的文件。附件名、未抽验文本和推测不能触发冲突定论。

触发 ROUTE001–004 时：

1. 把双方 `source/evidence/location`、冲突编号和受影响轴写入 `conflicts[]`。
2. 暂停受影响标签对应技能的执行，列出证据并请求人工确认；不得静默任选一边。
3. 已确认且不受冲突影响的其他轴与 overlay 命中继续保留，不得清空或覆盖其候选集合。
4. 人工确认后只重算受影响轴，再按 08 对全部轴重新求稳定并集。

多 overlay 合并与 ROUTE 冲突是两件事：无冲突时 overlay 技能全部并集装载；有冲突时仅挂起受影响部分，不得用冲突处理把不相干的业务、资产、方法、公共或覆盖层技能短路掉。
