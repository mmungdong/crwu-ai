## 多标签方法词表

从真实读取的报告摘要、评估方法选择章节、各方法测算章节和结论章节独立识别方法。每命中一种方法后继续扫描，不得把多方法压成单一标签。

| canonical 方法标签 | 常见表述 |
| --- | --- |
| 资产基础法 | 资产基础法、成本加和法 |
| 成本法 | 成本法、重置成本法 |
| 市场法 | 市场法、市场比较法、交易案例比较法、上市公司比较法 |
| 收益法 | 收益法、收益现值法、现金流量折现法、DCF |
| 假设开发法 | 假设开发法、剩余法 |
| 基准地价系数修正法 | 基准地价系数修正法 |
| 路线价法 | 路线价法 |
| 其他方法 | 报告明确采用但不属于以上 canonical 标签的方法；保留原名并人工复核 |

同一报告可同时命中 `资产基础法 + 收益法 + 市场法`。附件名仅能产生“方法待抽验”提示，不能产生已确认的 `methods[]` 标签。

## 方法角色

每个 `methods[]` 项必须记录 `role`：

- `采用-作结论`：报告明确选用/采用该方法，且最终结论取该方法结果。
- `采用-未作结论`：报告明确选用/采用该方法并形成结果，但最终结论未取该结果。结论未取不等于未采用。
- `测算-参考`：报告明确称其为辅助测算、验证或参考，未将其列为选用/采用的方法。

凡报告明确“选用/采用”的方法，即使最终未取其结果，也必须标为 `采用-未作结论`；只有报告明确为辅助验证时才可标 `测算-参考`。不得根据结果大小、行业惯例或附件名称反推角色。

## 结论方法

`conclusion_method` 与 `methods[]` 分开记录：

- 单一方法作结论时，记录该 canonical 方法及结论章节证据。
- 多方法加权、综合或区间作结论时，按报告原文记录全部参与结论的方法、权重或综合方式，不虚构单一结论方法。
- 报告未明确结论取值来源时，`conclusion_method=null`，加入材料缺口并人工复核。
- `conclusion_method` 中出现的方法必须能在 `methods[]` 找到对应项，且其角色为 `采用-作结论`。

方法专项审核至少覆盖：全部采用方法是否披露、结论方法选择理由是否说明、各法结果差异是否分析、差异较大是否解释，以及报告/说明/明细表的方法口径是否一致。

## source-location 契约

方法和结论方法只允许由真实读取的文件确认。每项必须保留 `source/evidence/source_loc`：

```jsonc
{
  "method": "收益法",
  "role": "采用-未作结论",
  "source": "评估报告文件",
  "evidence": "本次评估采用资产基础法和收益法……最终采用资产基础法结果",
  "source_loc": "评估说明·评估方法选择与结论章节(L730-748)",
  "confidence": "high",
  "review_required": false
}
```

未下载、不可读或未定位时，只能写 `未抽验（文件未读取）`，`source_loc=null`，不得用于 ROUTE 冲突定论。严禁凭记录字段、附件名、行业经验补写方法原文，或编造章节、页码、行号。文件下载、格式转换、隐藏数据隔离和定位前置按 [00-input-and-route-profile.md](00-input-and-route-profile.md) 执行。
