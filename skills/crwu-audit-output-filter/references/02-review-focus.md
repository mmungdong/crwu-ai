# 输出过滤规则

## 1. 读取有效记录

只读取《02-屏蔽清单》表格中 `状态=启用` 的记录。停用、字段缺失或表格无法解析的记录不执行。

## 2. 精确匹配

每条候选意见先形成稳定 `匹配标识`：

- 有 `checkId`：直接使用该编号；
- 无 `checkId`：仅使用已有受控字段编号构成 `字段编号:问题类型`；
- 禁止仅凭相似措辞、自由文本关键词或语义猜测扩大匹配。

## 3. 条件与例外

精确命中后，依次核对适用范围和屏蔽条件。任一条件不满足，或命中“不屏蔽例外”，均保留意见。

同一意见同时命中屏蔽和保留条件时，以保留为准。无法判断时也以保留为准。

## 4. 输出纪律

满足全部条件的候选意见不进入正式 `issues[]`，也不进入员工 HTML 的问题、摘要、建议或备注区域。不得变相输出被屏蔽意见的具体内容。

本能力只过滤正式输出，不把屏蔽规则解释成专业结论，也不为其他候选意见增删证据或改变严重度。
