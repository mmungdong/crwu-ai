# 房地产资产规则装配

**路径键写法**：逐字使用库内节点名（`crwu-dws` 的 `by_path` 键 = 原样精确名，不做大小写/全半角折叠）。**单文件路径不要加 `.md` 后缀**——`.md` 只是导出到本地时的文件名（`<节点名>.md`），不是库内节点名；带后缀会与 `by_path` 键不匹配而在 M2 记 failure。目录路径以 `/` 结尾并递归下载。

本表只保存 RULE/CHK 编号和库内层级路径寻址键。运行时由 `crwu-audit` 汇总清单，再由 `crwu-dws` 实时下载正文并生成本次 manifest；目录缓存只用于定位，正文文件零缓存，不得读取上一轮下载物。

清单条目有两种语义：不以 `/` 结尾的是单文件路径，只下载该文件；以 `/` 结尾的是目录路径，**递归下载其中全部支持正文**。清单外零下载。

## 3. 市场法协同边界

本技能只登记 §1 的房地产一级根，不再无条件持有方法层或公共层装配键。router 按本次画像动态装配：市场法通用准则、方法说明和跨方法缺陷由 `methods[]=市场法`／任一方法命中触发；不动产市场法专项清单仅在 `methods[]=市场法` 且 `asset_types[]=房地产` 时追加；易错点库由公共通用准则技能恒装配。

这保证三类内容在房地产市场法项目中取并集，同时避免房地产成本法、收益法或资产基础法项目误装市场法专项清单，也避免非房地产市场法项目缺少通用方法资料。

### 3.2 范围边界

- 方法正文与方法专项清单均由 router 按实际 `methods[]` 和显式跨轴条件装配，本表不预装。
- **监管正文**（国资/证券/司法/金融 overlay）仍属 overlay 轴，本表不登记。
- **`00-总纲/治理/` 下的回测与校准记录**属维护侧材料，不进入运行时下载清单；其结论只以 §3.1 “回指”形式体现（不下载）。

报告通用披露层、全局执行契约与校准/回测记录**不再由本表登记**：

- 报告披露（`RULE-01-02-251~279`）由 public 轴 `crwu-audit-public-general-standards` 恒装配（`06-规则库/02-通用准则-报告与披露/`），本技能不重复登记；
- 全局执行契约 `00-总纲/执行契约/02-防幻觉协议执行细则` 与 `00-总纲/执行契约/03-审核统计与台账规范` 由 router 步骤 9 作为强制契约并集下载，本表登记属重复；
- `00-总纲/治理/` 下的回测与校准记录属**维护侧材料**，不进入运行时审核依据下载清单。

方法正文属方法轴、监管正文属 overlay 轴，均由 router 的对应轴并集装配；本技能不据上述协同关系扩业务判断权。

本技能不选择租赁、清算、资产处置、拍卖、抵押质押等业务标签，也不装配业务专项路径；这些由 router 同时加载的业务轴 Skill 处理。不创建资产×业务组合 Skill。

## 4. 失败与出处

下载零命中、多命中、类型不符、跳过或失败时，以 manifest 状态记录对应 gap，不猜测近似路径。最终出处按 R6 由 manifest 与本次下载物共同形成：本次下载文件、实际行号、库内路径、运行时 `nodeId` 和 `exportedAt`；运行时值不得写回本文件。
