## 1. 引用协议与运行时真身（2026-09-08 实时引用协议；2026-09-10 本地根模型废止）

- **知识库 = 钉钉知识库（crwu-dws 实时下载源）**。技能正文不保存、不缓存知识库正文：引用一律写
  RULE/CHK 编号 + 库内层级路径寻址键（如 `00-总纲/执行契约/01-调度器-SKILL总纲`、`06-规则库/…`），不写知识库名称、
  不写本地根路径字面、不写 nodeId；需要正文时经 crwu-dws 按清单实时下载后只读引用
  （出处 = 本次下载文件:行号 + exportedAt，下载时刻即最新）。
- **本仓不再有本地知识库根**：`CRWU_KB_ROOT` 与 `KB/<相对路径>` 引用均已废止。技能侧只保留
  寻址键；是否存在、是否改名一律以 crwu-dws 的**最新目录**为准（本地目录缓存只用于定位加速，
  不能提供正文）。校验口径 = maintainer 技能的引用卫生 + "三不写" lint
  （禁知识库名称 / 禁本地正文路径字面 / 禁 nodeId 常量）；**命令、参数与判据见
  `crwu-dev-audit-skill-maintainer/references/05-validation-and-delivery.md`**，本文件不复制其命令签名。
- 运行时布局（事实）：技能按**层**组织，DSH 侧随**插件包**发布（一个层 = 一个技能根），
  其它宿主由 `make skills-install AGENT_DIR=<宿主 skills 根>` 落一份副本。
  **部署/同步由插件打包与用户执行**：维护者/agent 只改源仓并提交，
  不直接写/ln/cp/rm 任何运行时目录（校验以部署结果为准）。
- **校验工具归 maintainer**：引用/实时协议校验工具与映射检查器均属
  `crwu-dev-audit-skill-maintainer` 技能（随该技能安装），其调用方式与参数只在
  `crwu-dev-audit-skill-maintainer/references/05-validation-and-delivery.md` 维护一次；本文件只说明"有这两个工具"。
  装配清单不再由工具生成——下载清单 = 命中叶子的 `references/01-kb-assembly.md`（一级目录根或单文件路径）
  ＋ 执行契约路径并集，由 crwu-dws M2 实时下载。无工具时按装配表定位引用路径，正文一律经 crwu-dws
  实时下载后人工核对，**方案必须附手工证据**；下载不可得 → 显式报告。
- 本技能 references 随技能安装，内容自带寻址键表与落点地图，不回指源仓技能索引（那些文档不随技能安装）。

## 2.1 知识库变更的同步义务（装配表 / 知识库登记 两件套）

## 3. 红线（不许绕过）

1. **未出方案、未经用户确认，不动任何文件**（含 KB 内容）；
2. 不产审核判断、不出审核意见（那是 crwu-audit 流程）；
3. 不判定、不依赖"发布/待发布"状态（口径 2026-09-08：知识库文档即权威、下载即审——不存在发布状态
   判定与登记动作；内容侧历史"待发布"标注仅信息残留，AI 不读取判定，清理归知识库维护）；
4. 不把规则/清单正文复制进技能（技能=流程+寻址键+算法，正文=钉钉知识库，即 crwu-dws 实时下载源）；
5. 编号唯一性以定义锚点为准（正文区间引用不算重复）；
6. 个人绝对路径、「KB/…」式前缀省略、已废止的 `KB/<rel>` 本地根相对引用与 `CRWU_KB_ROOT` 常量、
   旧树目录名（01-规则库/02-审核清单库/执业准则-*/06-素材库-L2 等）一律禁止出现；
7. SKILL.md ≤300 行；改 crwu-audit 族技能前先读 `crwu-audit/references/99-maintenance.md`；
8. 每次改动只落源仓并提交；运行时部署由用户 skills 管理机制负责（不直接写/ln/cp/rm `~/.skills-manager`、`~/.dsh`、`~/.workbuddy` 等运行时目录）；登记三处（design/README/CHANGELOG）。
9. 知识库正文、目录、标签词典与治理记录均只允许经 `crwu-dws` 只读核对；修复统一标记 `manual_only` 并交用户人工执行，任何 CLI 禁止写入。
