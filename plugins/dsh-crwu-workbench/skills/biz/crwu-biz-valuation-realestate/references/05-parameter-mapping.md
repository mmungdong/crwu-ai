# 05 参数与税费

- **来源**：力鸿花园投资性房地产公允价值测算底稿「J统一价值内涵、及税费正常负担的测算」税费调整区、
  「收益法」运营费用区、「Sheet5 土地使用税计提明细」；现行增值税、房产税、城镇土地使用税、
  个人所得税与土地增值税相关规定。
- **适用范围**：房地产估值中市场法的税费正常负担还原与收益法的运营费用口径；住宅、商业、办公通用。
- **更新时间**：2026-10-12。

> 使用纪律：**税率是会变的**。本表给出的是口径与常见取值，实际取值必须以**评估基准日有效的规则正文**
> 或项目所在地税务机关要求为准（见 `01-房地产估值通用` 的引用纪律）。凡本表取值与实际正文不一致，
> 以正文为准并更新本表。

## 1. 交易环节税费（市场法口径）

| 税种 | 纳税人 | 计税基础 | 常见税率/口径 | 备注 |
| --- | --- | --- | --- | --- |
| 增值税 | 卖方 | 不含税销售额 | 企业处置不动产 9%；个人出租住房 1.5%；个人转让住房满足条件的免征 | 满五唯一住房转让通常免征 |
| 城建税 | 卖方 | 实缴增值税 | 市区 7%、县城/镇 5%、其他 1% | 增值税免征则一并免征 |
| 教育费附加 | 卖方 | 实缴增值税 | 3% | 同上 |
| 地方教育附加 | 卖方 | 实缴增值税 | 2% | 各地可能不同 |
| 土地增值税 | 卖方 | 增值额 | 四级超率累进 30%–60%；住宅个人转让常免征 | 企业转让非住宅常按核定征收率（如 5%） |
| 个人所得税 | 卖方（个人） | 转让所得或核定 | 核定常见 1% | 满五唯一免征 |
| 企业所得税 | 卖方（企业） | 转让所得 | 25%（优惠税率按企业类型） | 不体现在单价还原中，单独说明 |
| 契税 | **买方** | 成交价 | 1%–3%，按当地与套数/面积档 | 买方负担，还原时**加回** |
| 印花税 | 双方 | 合同金额 | 0.05% 或按当地口径 | 个人住宅交易多免征 |

### 1.1 税费正常负担的还原公式

市场法要求把"卖方净得价"还原为"交易双方各自负担法定税费的含税价"：

```text
含税总价 = 卖方净得价 + 卖方应负担税费合计 + 买方应负担税费合计
含税单价 = ROUND(含税总价 / 建筑面积, -1)
不含税单价 = ROUND((含税总价 − 增值税) / 建筑面积, -1)
```

其中：

- **卖方应负担税费合计** = 增值税（未免征时）+ 附加税合计 + 土地增值税 + 个人所得税（或所得税）
  + 印花税（卖方侧）；
- **买方应负担税费合计** = 契税 + 印花税（买方侧）；
- 任一税种**免征**时必须写明免征依据（如"满五唯一免征"、"个人转让住房免征土地增值税"），
  不得留空，也不得按 0 静默处理；
- 减征、核定征收等特殊口径同样必须写明来源。

### 1.2 税收优惠档（住宅常用）

还原之前先判定案例与估价对象的优惠档，档位不同必须分别修正：

| 档位 | 含义 | 常见影响 |
| --- | --- | --- |
| 满五唯一 | 持有满五年且为家庭唯一住房 | 增值税、个人所得税常免征 |
| 满五不唯一 | 持有满五年，非唯一 | 个税通常不免 |
| 满二唯一 / 满二不唯一 | 持有满两年 | 增值税免征，个税按档 |
| 无税收优惠 | 不满足持有年限 | 各税种按常规计征 |
| 无法核实 | 询价时无法确认是否唯一 | **按非唯一住房从宽认定**，并写明该处理 |

## 2. 持有环节税费（收益法运营费用口径）

| 税种 | 计税基础 | 常见口径 | 备注 |
| --- | --- | --- | --- |
| 增值税 | （有效毛收入 − 其他收入）÷ (1+税率) × 税率 | 企业出租不动产 9%；个人出租住房 1.5% | 与租金含税口径必须一致 |
| 城建税及两项附加 | 实缴增值税 | 7% / 3% / 2%（按所在地） | 增值税免征则免征 |
| 房产税 | （有效毛收入 − 其他收入 − 增值税）× 12% | 从租计征 12%；个人出租住房常按 4% | 出租主体决定税率 |
| 城镇土地使用税 | 年税额/㎡ ÷ 容积率（元/㎡·年） | 按当地地段等级标准，如 24 元/㎡·年 | 按土地面积分摊，须用当地标准 |
| 印花税 | （有效毛收入 − 其他收入 − 增值税）× 1‰ | 财产租赁合同 | 个人出租住房常免征 |
| 维修费 | 建筑重置成本 × 2% | 保证正常使用的修缮费用 | 重置成本来源须写明 |
| 保险费 | 建筑重置成本 × 1‰ | 财产保险 | 与维修费共用同一重置成本基数 |
| 管理费 | 有效毛收入 × 2% | 出租管理必要费用 | 费率依据须写明 |

**出租主体判定优先于一切**：个人、个体户、企业适用税率不同。出租主体不明时先挂起该口径，
不得默认按企业税率计算（会高估税负、低估价值），也不得默认按个人优惠税率计算。

## 3. 参数缺省值与取值依据

下表列可调参数的常见区间。**取值必须写依据，缺省值不能直接当结论**。

| 参数 | 常见区间 | 取值依据要求 |
| --- | --- | --- |
| 空置率 | 住宅 0%–10%；商业/办公 5%–20% | 当地同类物业调查、项目历史出租率 |
| 报酬率 Y | 住宅 5%–7%；商业/办公 6%–9% | 安全利率 + 风险调整值分项 |
| 增长率 g | 0%–3%（长期模型宜低于 Y） | 区域租售调查与预测 |
| 押金月数 | 住宅 1 个月；商业 1–3 个月 | 租约或市场惯例 |
| 一年期存款利率 | 按基准日人行公布值，如 0.95% | 基准日时点与来源 |
| 管理费率 | 2% | 项目实际或行业惯例 |
| 维修费率 | 2% | 房屋状况与行业惯例 |
| 保险费率 | 1‰ | 保险公司报价 |
| 房产税率 | 12%（企业从租）；4%（个人出租住房） | 出租主体 + 当地口径 |
| 土地使用税标准 | 按地段等级，如 24 元/㎡·年 | 当地税务标准 + 容积率 |
| 土地增值税核定征收率 | 如 5%（非住宅企业转让） | 项目所在地税务机关口径 |
| 个人所得税核定征收率 | 如 1% | 当地口径 |

## 4. 参数登记要求

每个参数落表时同时记录五项，缺任一项即为不合格：

| 登记项 | 内容 |
| --- | --- |
| 参数名 | 与计算表字段名一致 |
| 取值 | 数值（含单位） |
| 依据 / 来源 | 规则正文条款、询价记录、项目资料、税务口径 |
| 时点 / 有效期 | 评估基准日或取得日期 |
| 取数人 / 待确认 | 谁取的；是否需要人工确认 |

参数集中登记在计算表「基础信息表」的"参数与税率"区，供市场法与收益法共用，避免两处各填一套。

## 5. 常见错误

- 免征与"取 0"混为一谈，无法区分是政策免征还是漏填；
- 卖方净得价还原时只加卖方税费，忘了买方契税，或反之重复计入；
- 增值税与附加税口径不一致（增值税免征但附加税仍计提）；
- 出租主体未判定就先套税率；
- 个人出租住房用企业 12% 房产税率，或企业用 4% 优惠税率；
- 城镇土地使用税直接用年税额，未按容积率/土地面积分摊；
- 维修费与保险费各填一个重置成本，数值不一致；
- 税率取值未标注基准日与正文出处，导致复核时无法判断是否过期。
