# 07 成本法

- **来源**：《房地产估价规范》GB/T 50291 成本法口径；力鸿花园投资性房地产公允价值测算底稿的
  建筑重置成本口径；《资产评估执业准则——不动产》建筑物重置成本与成新率测算要求。
- **适用范围**：房地产（住宅、商业、办公、投资性房地产）成本法测算；适用于无足够可比案例、
  收益不稳定或不可预测、特殊用途房屋，或非市场化评估目的（抵押、课税、拆迁补偿、保险等）。
- **更新时间**：2026-10-12。

## 1. 计算链

成本法是**积算**路径，最后乘建筑面积得评估值：

```text
建筑重置成本单价（元/㎡）
→ 成新率 = 尚可使用年限 / 经济耐用年限（使用年限法）或观察法打分
→ 建筑物评估单价 = 建筑重置成本单价 × 成新率
→ 土地单价（成本逼近法 / 基准地价系数修正法 / 市场法取得）
→ 房地产积算单价 = 建筑物评估单价 + 土地单价
→ 房地产评估值 = 房地产积算单价 × 建筑面积
```

## 2. 适用与选择

成本法在以下情形采用，且必须在结论中写明采用理由：

| 情形 | 说明 |
| --- | --- |
| 市场法不可用 | 同一供需圈内没有足够、可核的近期成交案例（见 `02-市场法` 第 2 节） |
| 收益法不可用 | 没有稳定或可预测的租金收益、收益年限不确定 |
| 特殊用途房屋 | 交易或租赁市场不活跃，可比性差 |
| 非市场化评估目的 | 抵押、课税、拆迁补偿、保险、出资等不以公开市场交易为前提的目的 |

约束与提示：

- 成本法积算价通常**低于**市场价值。与市场法/收益法结论差异较大时，必须在结论中说明差异原因，
  不得把三者强行平均。
- 选定成本法为结论方法时，在「估值结果汇总」标注「成本法」；其余方法测算过程仍保留作验证。

## 3. 建筑重置成本

重置成本按**评估基准日**的现行造价水平确定，取值为**更新重置成本**（以现行材料、工艺重建），
不用**复原重置成本**（原样原工艺重建，只在有特别依据时采用并写明）。

| 取值方式 | 说明 | 必须留痕 |
| --- | --- | --- |
| 直接取得 | 造价指标、预算定额、竣工决算、类比项目 | 来源文件、时点、是否含税费 |
| 分项构成 | 建安综合造价 ×(1 + 前期及其他费用率 + 管理费率 + 资金成本率 + 开发利润率) | 各费率取值与来源 |

- 建安综合造价含人工、材料、机械与措施费；不含前期费用、管理费用、资金成本与利润。
- 重置成本与维修费/保险费共用同一基数时，公式必须互引，不得各填一个数（见 `03-收益法` 第 6 节）。
- 重置成本**不含土地**：土地单独测算后相加。

## 4. 成新率与贬值

成新率反映建筑物现状相对全新状态的比值，两种方法可并用：

| 方法 | 公式 | 适用 |
| --- | --- | --- |
| 使用年限法 | `成新率 = 尚可使用年限 / 经济耐用年限` | 有明确建成年代、经济耐用年限可取时 |
| 观察法（打分） | 按结构、装修、设备三部分打分加权 | 现场可勘察时，与年限法互相印证 |

贬值分为三类，分别估算后综合：

| 贬值 | 含义 | 处理 |
| --- | --- | --- |
| 实体性贬值 | 使用与自然损耗 | 使用年限法 / 观察法 |
| 功能性贬值 | 设计、布局、工艺落后 | 有确实证据时单列扣减，说明依据 |
| 经济性贬值 | 外部环境不利（需求、政策、规划） | 有确实证据时单列扣减，说明依据 |

- 成新率与贬值率互补：`成新率 = 1 − 综合贬值率`，同一测算内两套口径不得混用。
- 已使用年限从竣工/建成到基准日；尚可使用年限须结合现场勘察与维护状况确定，
  不得简单用 `经济耐用年限 − 已使用年限` 而不勘察。

## 5. 经济耐用年限

| 结构 | 经济耐用年限参考 |
| --- | --- |
| 钢 / 全钢结构 | 60–80 年 |
| 钢筋混凝土结构 | 50–60 年 |
| 砖混结构 | 40–50 年 |
| 砖木结构 | 30–40 年 |

- 取当地或项目具体依据为准；结构以权证或现场勘察为准。
- 住宅用地到期自动续期的，土地端按最高年限处理；此时经济耐用年限通常决定剩余年限口径。

## 6. 土地单价

土地单价单独测算，三种路径任选，必须有来源与依据：

| 路径 | 说明 |
| --- | --- |
| 成本逼近法 | 土地取得成本 + 开发费用 + 相关税费 + 利息 + 利润 + 土地增值收益 |
| 基准地价系数修正法 | 当地基准地价 × 期日、区位、用途、容积率等修正系数 |
| 市场法 | 有可比土地交易时，按可比实例修正 |

- 土地单价与建筑物重置成本口径必须一致（同一基准日、同一内涵）。
- 房屋与其对应土地权益必须成对处理（见 `01-房地产估值通用` 第 1 节）；只算建筑物、漏掉土地，
  或把土地重复计入重置成本，都是不合格交付。

## 7. 计算与取整约束

- 成新率保留两位小数（百分比）。
- 建筑物评估单价、土地单价、房地产积算单价：`ROUND(..., -1)` 到十位。
- 房地产评估值：`ROUND(房地产积算单价 × 建筑面积, -2)` 到百位。
- 三处勾稽：`0 < 成新率 ≤ 100%`；重置成本 > 0；`单价 × 建筑面积` 与「估值结果汇总」评估值一致。

## 8. 常见错误

- 重置成本含土地又另加土地单价，重复计入；
- 用复原重置成本却未写明依据；
- 已使用年限算到勘察日而非基准日；
- 尚可使用年限不经勘察直接相减，成新率失真；
- 成新率与贬值率两套口径混用；
- 功能性/经济性贬值无证据就扣减，或该扣不扣；
- 成本法结论与市场法/收益法差异大却不说明原因；
- 土地单价无来源，或与建筑物口径不一致。
