# 02 市场法

- **来源**：力鸿花园投资性房地产公允价值测算底稿「J统一价值内涵、及税费正常负担的测算
  （房屋建筑物市场法通用）」「J住宅市场法表」现行公式与修正体系；《房地产估价规范》GB/T 50291
  关于可比实例修正幅度的要求。
- **适用范围**：房地产（住宅、商业、办公）市场法测算；修正因素体系按用途分档，通用框架一致。
- **更新时间**：2026-10-12。

## 1. 计算链

市场法是一条**单向链**，任何一环取值都必须留痕：

```text
候选案例（含来源与链接）
→ 统一价值内涵与税费正常负担（见 05）
→ 比较因素条件说明（文字描述 + 逐因素档次）
→ 比较因素条件指数（估价对象 = 100，案例打分）
→ 比较因素修正系数（待估/案例）
→ 比准价格 = 交易单价 × 修正系数积
→ 评估单价 = 各比准价格的算术平均（取整）
→ 评估值 = 评估单价 × 建筑面积
→ 含增值税口径（如需要）
```

## 2. 案例选用条件

可比实例必须满足：与估价对象**用途相同、结构相近、处于同一供需圈**，成交日期接近基准日
（一般不超过一年，超过则必须做日期修正并说明），且成交价格是**正常交易或可修正到正常交易**的价格。

数量：**不少于 3 个**。不足 3 个时按 `05-案例选取` 的规则处理并写入待确认事项，
不得用 2 个案例直接平均后当结论。

## 3. 建立比较基础（统一价值内涵）

在打分之前先把三个案例与估价对象拉齐到同一口径（口径定义见 `01-房地产估值通用` 第 4 节）：

| 统一项 | 统一为 | 不一致时 |
| --- | --- | --- |
| 财产范围 | 纯粹、干净房地产 | 带家具家电/设备/租约的单列修正 |
| 付款方式 | 成交日一次总付清 | 分期、贷款价格先修正 |
| 融资条件 | 常规融资条件 | 非常规融资先修正 |
| 税费负担 | 双方各自负担法定税费 | 卖方净得价、税费非正常负担先还原 |
| 计价单位 | 人民币元/建筑平方米 | 按套内面积/按套计价先换算 |
| 含税 | 与估价对象同一口径 | 含税与不含税先换算 |

**未完成统一就开始打分的，测算作废重来。** 这一节是市场法出错最多的地方：税费口径没对齐时，
后面所有修正系数都建立在错误基数上。

## 4. 交易情况修正

把案例成交价格修正为正常交易价格。判断"是否正常"的场景清单：

1. 有利害关系人之间的交易；
2. 急于出售或急于购买情况下的交易；
3. 受债权债务关系影响的交易；
4. 交易双方或一方对市场行情缺乏了解的交易；
5. 交易双方或一方有特别动机或特别偏好的交易；
6. 相邻房地产的合并交易；
7. 特殊方式的交易（拍卖、招标、挂牌等）；
8. 交易税费非正常负担的交易；
9. 其他非正常的交易。

命中任一项时**必须修正并写明修正幅度与理由**，不得默认为 1。挂牌价（报价）属于待修正情形：
挂牌价系统性高于成交价，需按当地挂牌成交价差经验或询价结果向下修正，并在备注中写明来源。

## 5. 交易日期修正

- 优先用当地房地产价格指数（住宅可采用国家统计局 70 个大中城市住宅销售价格指数中对应城市
  的新建/二手住宅环比或定基指数）。
- 无适用指数时，用同区域同类房地产的价格变动调查结果，并在备注中写明调查方式与样本。
- 修正到**评估基准日**，不是修正到"最近一个月"。
- 案例成交日期与基准日相差不足一个指数周期时，可记为 100，但必须写明判断依据。

## 6. 区位状况修正因素体系（住宅口径）

以估价对象为 100，逐因素给案例打分。下表档次与幅度取自现行住宅底稿体系，**改幅度要有依据**，
不得凭主观调整。

| 因素 | 分档 | 幅度 |
| --- | --- | --- |
| 住宅的集聚度 | 高 / 较高 / 一般 / 较低 / 低 | 每差一档 5% |
| 距商业中心（商场、大型超市）距离 | 核心 / 次核心 / 边缘 | 每差一级 3% |
| 公交便捷程度 | 优（10 条以上）/ 较优（5–10 条）/ 一般（3–5 条）/ 较差（1–3 条）/ 差（无）；附近有地铁站点为优 | 每差一级 2% |
| 通达性 | 好 / 较好 / 一般 / 较差 / 差（按周边道路数量与级别） | 每差一档 1% |
| 接近性 | 好（落车位 50m 内）/ 较好（50–100m）/ 一般（100–300m）/ 较差（300–500m）/ 差（500m 以上） | 每差一档 1% |
| 景观 | 好 / 较好 / 一般（水景、山景、公园、道路、小区等） | 每差一档 1% |
| 周边环境状况 | 好 / 较好 / 一般 / 较差 / 差（自然与人文环境） | 每差一档 1% |
| 面积与配套车位数量比 | 充足 / 一般 / 不足 | 每差一档 2% |
| 公共配套设施 | 优 / 较优 / 一般 / 较差 / 差（银行、邮电、餐饮娱乐、商场等，按指标增减） | 每增减一个指标 1% |
| 教育配套设施 | 大学 / 中学 / 小学 / 幼儿园（每增减一个指标） | 每增减少一个指标 2%；有名校可再调增 1% |

商业、办公用途：**区位状况权重高于住宅**，增收或替换以下因素——临街状况、临街深度、商业繁华度、
商圈等级、楼层商业适应性、人流动线、办公聚集度、商务配套。幅度参照当地商业/办公底稿体系，
改档必须有调查依据。

## 7. 实物状况修正因素体系（住宅口径）

| 因素 | 分档 | 幅度 |
| --- | --- | --- |
| 住宅类型 | 板楼 / 塔楼；梯户比；是否纯住户 | 据实测算（现行底稿：塔楼相对板楼每档 2%） |
| 委估资产在小区内的具体位置 | 临街 / 小区内部 / 临配套 | 据实修正 |
| 外观形象 | 好 / 较好 / 一般 / 较差 / 差 | 每差一档 1% |
| 装修状况 · 公共区域 | 高级精装 / 一般精装 / 粗装 / 毛坯 | 每差一级 1% |
| 装修状况 · 室内装修区域 | 高档装修 / 精装（中档）/ 简单装修 / 毛坯 | 每差一级 5% |
| 面积大小 | 按建筑面积区间 | 每相差 50 ㎡ 1%，面积递增、修正系数递减 |
| 配套设备设施 | 齐全 / 较齐全 / 一般（电梯、安防、网络等） | 每差一级 1% |
| 土地红线内基础设施 | 七通以上 / 七通 / 六通 / 五通 / 四通及以下 | 每差一级 2% |
| 物业管理水平 | 高 / 较高 / 一般 / 较低 / 低 | 每差一档 1% |
| 是否有学区资格 | 重点小学/初中学区；资格是否已被占用；多久后恢复 | 据实修正 |
| 成新及维护保养状况 | 建成年代 + 维护保养级别 | 建成年代每差 2 年、保养每差一级各 2%，求和 |
| 建筑结构 | 全钢 / 全钢+钢混 / 钢混 / 砖混 | 每差一级 3% |

**装修修正要分开做**：公共区域与室内装修区分开打分，不得合并成一个"装修"因素。
室内装修幅度大于公共区域（5% vs 1%），合并会显著放大误差。

## 8. 权益状况修正

| 因素 | 处理 |
| --- | --- |
| 租赁权 | 按合同租金与市场租金差异、剩余租期据实确定修正指数；有无租约必须核实 |
| 抵押权 | 产权持有人承诺转让前解除抵押的，本次不修正，但结论中必须写明该假设 |
| 土地剩余经济年限 | 用年期修正系数公式确定；住宅用地到期自动续期的一般不修正，须写明依据 |
| 其他权利限制 | 查封、共有、划拨土地等，先确认是否在价值内涵内，再决定修正或设定假设 |

## 9. 计算与约束

- **修正系数积**：`修正系数积 = ROUND(Π(估价对象因素指数) / Π(案例因素指数), 4)`
- **比准价格**：`比准价格 = ROUND(案例交易单价 × 修正系数积, -1)`（保留到十位）
- **评估单价**：`评估单价 = ROUND(各比准价格算术平均, -1)`
- **评估值**：`评估值 = ROUND(评估单价 × 建筑面积, -2)`（保留到百位）
- **含增值税口径**：`含税单价 = ROUND(不含税单价 × (1 + 增值税率), -1)`；
  `增值税 = 含税单价 − 不含税单价`。增值税率取企业处置该资产适用税率（如 9%），来源见 `05`。

三项硬约束，超限必须在底稿中说明理由或重选案例：

1. 单项因素对可比实例成交价格的修正或调整幅度**不宜超过 20%**；
2. 全部因素共同对可比实例成交价格的修正和调整幅度**不宜超过 30%**；
3. 经修正调整后各可比实例价格中，**最高价与最低价的比值不宜大于 1.2**。

计算表中必须放一个比值检查单元格（`MAX(比准价格)/MIN(比准价格)`），超过 1.2 时在结论中说明处置方式
（剔除离群案例 / 改用加权平均 / 说明原因后保留），不得静默忽略。

三条约束用 `scripts/market_rules.py` **算**（不要心算），判定结果是 `within` / `at-limit` / `over`：

- **"不宜"是软约束**：`over` 不表示案例必须删掉，而是**必须说明处置方式**；
- **等于阈值算到限**（`at-limit`），不算超；
- **综合修正是各系数的连乘**，不是把百分比相加（两项各 +10% 是 21%，不是 20%）。

每次判定都要落进 `估值结果.json` 的 `cases[].rule_checks`（规则 ID、实际值、阈值、判定、理由），
规则 ID 与阈值口径见 `09-output-contract.md` 第 5.1 条。

## 10. 常见错误

- 税费口径没统一就打分，导致全链基数错误；
- 挂牌价未做交易情况修正，直接把报价当成交价；
- 用两个案例平均后当三个案例的结论；
- 装修因素合并打分，或把公共区域与室内装修用同一幅度；
- 日期修正用错指数口径（同比与环比混用、修正到非基准日）；
- 比值检查缺失或超 1.2 未说明；
- 案例缺失成交日期或来源链接，导致可比性无法复核。
