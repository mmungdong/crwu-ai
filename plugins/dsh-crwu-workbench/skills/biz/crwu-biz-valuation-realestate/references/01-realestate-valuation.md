# 01 房地产估值通用

- **来源**：中瑞世联评估审核知识库 · 房地产（房建类）审核条目；《房地产估价规范》GB/T 50291 术语口径；
  力鸿花园投资性房地产公允价值测算底稿（2025-12-31 基准日）的实际口径。
- **适用范围**：中国大陆资产评估业务中房地产（住宅、商业、办公、投资性房地产）的估值口径统一；
  不覆盖土地单独评估、矿业权、境外房地产。
- **更新时间**：2026-10-12。

## 1. 评估对象

估值开始前必须把评估对象锚定到**可指认、可核对**的四要素，缺一即挂起该对象：

| 要素 | 要求 | 常见缺失 |
| --- | --- | --- |
| 权属 | 权证编号、证载权利人、证载用途、土地证号/对应关系 | 只有房号没有权证；权证权利人与委托方不一致 |
| 坐落 | 具体门牌到房间号，不能只到小区 | 只写小区名，无法定位可比案例 |
| 面积 | 建筑面积（㎡），并注明是建筑面积还是套内建筑面积 | 面积来源不明，或与权证不符 |
| 用途 | 居住 / 商业 / 办公 / 工业等，与权证用途一致 | 实际用途与证载用途不一致未说明 |

评估对象是**房地产**（房 + 对应土地权益），不是单独的房屋或单独的土地。房屋与其对应土地权益
必须成对处理：房屋估值口径含其分摊或对应的土地权益，不得只算建筑物本身。

## 2. 价值类型

| 价值类型 | 内涵要点 | 适用 |
| --- | --- | --- |
| 市场价值 | 自愿交易、双方理性、信息充分、正常交易条件下的最可能价格 | 绝大多数估值业务 |
| 投资价值 | 特定投资者视角的价值，含特定协同或约束 | 仅当项目明确要求 |
| 公允价值 | 会计准则口径，有序交易中的脱手价 | 投资性房地产公允模式、财务报告目的 |
| 清算价值 / 快速变现 | 强制或限时处置条件 | 司法、处置类业务 |

价值类型决定方法选择与参数口径；**价值类型未定不得开始测算**。投资性房地产采用公允价值模式计量时，
价值类型取公允价值，与市场价值口径接近但要按会计准则表述，并在结论中写明。

## 3. 评估基准日

- 基准日必须是**明确到日**的日期，全表口径一致：交易日期修正、可获收益年限、剩余土地使用年限
  全部以基准日为起点。
- 基准日与现场勘察日不同时，分别记录：勘察日反映实物状况，基准日锚定价值时点。
- 收益年限起点取基准日；终点取"土地使用权终止日"与"建筑物终止日"中**较早者**（孰短原则）。

## 4. 价值内涵

价值内涵是本业务最容易出错、也最需要显式写清的部分。以下六项必须逐项确定并写入交付：

1. **财产范围**：设定为"纯粹""干净"的房地产（不含家具家电、设备、债权债务）；
   带家具家电或带租约的，单列修正，不得混入单价。
2. **付款方式**：统一为成交日一次性付清；分期或贷款价格的，先修正到一次总付清。
3. **融资条件**：统一为常规融资条件。
4. **税费负担**：统一为**交易双方各自负担法定应由其负担的税费**；卖方净得价、税费非正常负担的
   成交价一律先还原到正常税费负担口径。细则见 `06-参数与税费`。
5. **计价单位**：统一为人民币元/建筑平方米；按套内面积或按套计价的先换算。
6. **含税与否**：明确是含增值税价还是不含增值税价。**同一份测算内不得混用**；
   市场法与收益法必须统一到同一口径后比较。

## 5. 面积与税费口径

- **面积**：以建筑面积为计价面积；权证面积与实测面积不一致时，以权证为准并在待确认事项中写明差异。
  公摊、赠送面积只作实物状况修正因素，不改变计价面积。
- **税费**：区分**交易环节**（增值税及附加、土地增值税、个人所得税/企业所得税、契税、印花税）
  与**持有环节**（房产税、城镇土地使用税、印花税）。市场法比准价格统一到交易环节正常负担的
  不含税价；收益法运营费用含持有环节税费。逐税种口径见 `06-参数与税费`。
- **一手与二手差异**：一手房价格含开发商税费转嫁，二手房为卖方净得价时须加回卖方应负担税费，
  再统一到正常负担口径。

## 6. 方法选择

| 条件 | 采用 |
| --- | --- |
| 同一供需圈内有足够、可核的近期成交案例（一般 ≥ 3 个） | 市场法 |
| 有稳定或可预测的租金收益，且收益年限可确定 | 收益法 |
| 无足够可比案例、收益不稳定或不可预测，或特殊用途房屋、非市场化评估目的 | 成本法 |
| 多种方法都可用 | 分别测算后比较，选定一种作为结论并写明理由 |
| 都不可用 | 登记能力缺口与待确认事项 |

选定结论方法后，在计算表"最终估值结果汇总"中标注采用的方法（市场法 / 收益法 / 成本法），
未采用方法的测算过程同样保留在底稿中作为验证。

## 7. 一次估值的完成判据

同时满足才算完成：

1. 评估对象四要素齐备，价值类型、基准日、价值内涵六项均已确定；
2. 采用方法的测算在计算表中可逐格复算，无 `#REF!`、无断链、无隐藏表依赖；
3. 参数与税率均写明取值依据与来源；
4. 输出单价、总价与采用结论的方法及理由，并列出待确认事项；
5. 交付中写明本次实际读到的知识正文版本（含更新时间）。
