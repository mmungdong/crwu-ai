# 03 收益法

- **来源**：力鸿花园投资性房地产公允价值测算底稿「收益法」表现行公式与参数说明；《房地产估价规范》
  GB/T 50291 报酬资本化法口径。
- **适用范围**：有稳定或可预测租金收益的房地产（住宅出租、商业、办公、投资性房地产）收益法测算。
- **更新时间**：2026-10-12。

## 1. 计算链

收益法全表以**元/㎡**为单位纵向推进，最后乘可收益建筑面积得总价：

```text
日租金（元/㎡·天）
→ 年潜在毛收入 = 日租金 × 365
→ 年有效毛收入 = 潜在毛收入 − 空置损失 + 其他收入
→ 年运营费用 = 增值税及附加 + 管理费 + 房产税 + 城镇土地使用税 + 印花税 + 维修费 + 保险费
→ 年净收益（A）= 有效毛收入 − 运营费用
→ 收益价值（单价）= ROUND(A / (Y − g) × (1 − ((1+g)/(1+Y))^n), 0)
→ 收益价值（总价）= ROUND(单价 × 可收益建筑面积 / 10000, 2)（万元）
```

## 2. 参数清单

| 参数 | 取值口径 | 必须留痕的内容 |
| --- | --- | --- |
| 日租金 | 市场租金，由案例租金反算：`日租金 = ROUND(月含税租金 × 12 / 建筑面积 / 365, 2)` | 租金案例来源、面积、含税口径 |
| 空置率 | 按当地同类物业调查或项目实际空置情况 | 调查区间与取值理由 |
| 其他收入 | 押金利息：`保证金 = 日租金 × 押金月数(天)`，`利息 = 保证金 × 一年期存款利率 × (1 − 空置率)` | 押金月数、存款利率及时点 |
| 增值税 | `ROUND((有效毛收入 − 其他收入) / (1 + 税率) × 税率, 2)` | 适用税率及来源 |
| 城建税 / 教育附加 / 地方教育附加 | 增值税 × 各自税率（如 7% / 3% / 2%），地区差异须核实 | 项目所在地适用税率 |
| 管理费 | 有效毛收入 × 费率（如 2%） | 费率依据 |
| 房产税 | `ROUND((有效毛收入 − 其他收入 − 增值税) × 12%, 2)` | 计税口径与税率 |
| 城镇土地使用税 | `ROUND(年税额/㎡ ÷ 容积率, 2)`；按土地面积分摊 | 当地年税额标准、容积率来源 |
| 印花税 | `ROUND((有效毛收入 − 其他收入 − 增值税) × 1‰, 2)` | 税目与税率 |
| 维修费 | 建筑重置成本 × 费率（如 2%） | 重置成本来源（造价/决算/类比） |
| 保险费 | 建筑重置成本 × 费率（如 1‰） | 费率为保险公司报价 |
| 报酬率 Y | 安全利率 + 风险调整值 | 安全利率时点与来源；风险调整值构成 |
| 增长率 g | 区域房屋租售调查与预测 | 调查样本与判断依据 |
| 收益年限 n | 孰短原则：min(剩余土地使用年限, 剩余建筑物经济寿命) | 两端的起止日期与计算过程 |
| 残值 V′ | 以建筑物经济耐用年限为收益年限时通常为 0；有残值的单列 | 残值判断依据 |

## 3. 收益年限（孰短原则）

- 起点：**评估基准日**。
- 终点：土地使用权终止日与建筑物终止日中的**较早者**。
- `n = ROUND((终止日 − 基准日) / 365, 2)`，单位年。
- 住宅用地到期自动续期的，土地端按最高年限处理，但必须在底稿写明该口径及其依据；
  此时通常由**建筑物剩余经济寿命**决定 n。
- 年限取值直接影响结论：`n` 每差一年对结果的影响要在敏感性说明中体现（收益期较短的尤其明显）。

## 4. 报酬率

`报酬率 = 安全利率 + 风险调整值`。

- **安全利率**：取评估基准日中国人民银行公布的一年期存款利率，写明时点。
- **风险调整值**：= 投资风险补偿率 + 管理负担补偿率 + 缺乏流动性补偿率 − 投资带来的优惠率。
  取值需结合当地房地产业平均收益状况、估价对象地理位置与用途、当前通货膨胀与风险利率水平综合确定。
- 底稿中必须写清**安全利率取多少、风险调整值取多少、合计多少**，只写合计结论不合格。
- 商业、办公的报酬率一般高于住宅，差异要有调查依据，不能只写"经验取值"。

## 5. 增长率

- 由该区域房屋**租售调查及预测**确定，写明样本区间与来源。
- 与报酬率的关系决定公式形态：`Y > g` 时用等比递增年金公式；`Y ≤ g` 时该公式不成立，
  必须改用其他模型或说明处置方式，**不得**让公式算出负数或异常大值。
- 增长率不宜长期高于报酬率；长期模型下两者关系要在结论中说明。

## 6. 运营费用

- 运营费用是**出租人实际负担**的费用，不含承租人负担部分（如承租人自用的水电燃气）。
- 增值税及附加按"有效毛收入 − 其他收入"为计税基础，不含税口径要与租金口径一致。
- 房产税、印花税按不含税口径计算，避免重复计税。
- 维修费与保险费共用同一建筑重置成本基数时，两个基数值必须一致（公式应互引而非各自输入）。
- 维修费率的适用前提（房屋正常使用）要在备注中写明。

## 7. 住宅出租的特殊口径

- 个人出租住房的增值税、房产税常适用**减征优惠**；企业持有出租不适用。
  必须先确认**出租主体**（个人 / 企业 / 个体户），再定税率，出租主体不明时先挂起。
- 住宅出租的押金月数通常为 1 个月，商业常见 1–3 个月；取值要有租约或市场惯例依据。
- 住宅空置率通常低于商业办公；若采用与商业相同空置率，须说明理由。

## 8. 常见错误

- 租金含税/不含税口径与运营费用口径混用，导致增值税重复或漏计；
- 空置率、运营费用率凭经验取值，无调查来源；
- 城镇土地使用税直接用年税额，未按容积率或土地面积分摊；
- 维修费与保险费基数不一致；
- 报酬率只写合计值，不写安全利率与风险调整值的构成；
- `Y ≤ g` 时仍套用等比递增公式；
- 收益年限起点用勘察日而非基准日；
- 收益法单价与市场法单价不统一到同一增值税口径就相互比较。
